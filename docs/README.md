# Seovate — Autonomous SEO Agent Platform

MVP planning documentation set. No code has been written — this is strategy, research, and architecture only, per the founder's directive.

**Ground rules for this doc set:** every competitive, pricing, and API claim below is sourced from live web research done in September 2026. Where a figure could not be independently verified, it is explicitly flagged as unverified/unconfirmed rather than stated as fact. Do not treat unflagged numbers as guaranteed current by the time you read this — re-verify vendor pricing and API terms before committing spend.

**Founder decisions locked in (2026-09-11):**
- Target customer: small business / local SEO (not enterprise, not SaaS content teams)
- Team: solo founder, bootstrapped, <$500/mo tool budget initially
- Publishing model: direct CMS integration (WordPress-first) with zero human approval in the loop
